# DevTask Tracker - Stack 3 (Monolith Distinct Stack)

Versi ini menggunakan pendekatan arsitektur **Monolith** yang berbeda dari dua versi sebelumnya, di mana server langsung melayani template HTML.

## Tech Stack
- **Backend:** Flask (Python)
- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **Database:** SQLite (Relational Database)

## Prerequisites
- Python 3.9+

## Installation & Set-up
1. Buka terminal di folder ini.
2. Buat virtual environment: `python -m venv venv`.
3. Aktifkan venv: `venv\Scripts\activate` (Windows).
4. Install dependensi:
   ```bash
   pip install flask
